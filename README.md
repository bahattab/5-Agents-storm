# 5 Agents storm

Portable Agent Skill displayed as **0 - 5 Agents storm**. Trigger phrases: **5 Agents storm**, **5 Agents**, **storm** (when invoked as an analysis method).

Copy this folder into your agent host's skills directory. With no skill loader, read or supply `SKILL.md` as task instructions. No dependencies, credentials or installation commands are required. Trigger discovery depends on the host. Codex-compatible UI metadata is optional; the Markdown skill is the portable entrypoint.

Storm integrates practical feasibility, evidence quality, skeptical checks, incentives and historical patterns into one flowing synthesis. It preserves uncertainty and citations without presenting five separate opinions or private deliberation. It normally uses one agent; genuine separate agents are optional when explicitly requested and supported.

Example: `5 Agents storm: assess whether our small team should build or buy its internal scheduling system.`

مثال: `storm: حلّل قرار بناء نظام داخلي لإدارة المواعيد أو شراء خدمة جاهزة، وقدّم خلاصة متدفقة بالعربية.`
